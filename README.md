# Feles

Feles is a set of soft, dark and light themes in seven cat coats:

| Coat | Color | Dark | Light |
|---|---|---|---|
| **Cinnamon** | Red | `#bc5f5e` | `#9c3639` |
| **Russian Blue** | Teal | `#8abbaf` | `#377263` |
| **Siamese** | Blue | `#3574f0` | `#2b62d9` |
| **Marmalade** | Gold | `#d7a54b` | `#9a6700` |
| **Lilac** | Lavender | `#a895db` | `#7651c2` |
| **Chartreux** | Sage | `#a7c080` | `#5f7d2e` |
| **Tuxedo** | Silver | `#b4b9c2` | `#5a6372` |

To install:
  1.  Open Extensions (Ctrl+Shift+X, or ⇧⌘X on Mac) and search for **Feles Theme**.
  2.  Click **Install**.
  3.  Click **Set Color Theme**, or press Ctrl+K Ctrl+T (⌘K ⌘T on Mac), and pick a Feles theme, for example `Feles Siamese Dark`.

To switch between the dark and light version with your system theme, add this to your settings:

```json
"window.autoDetectColorScheme": true,
"workbench.preferredDarkColorTheme": "Feles Siamese Dark",
"workbench.preferredLightColorTheme": "Feles Siamese Light"
```

### For the full look

These settings go well with any Feles theme:

```json
"editor.fontFamily": "JetBrains Mono",
"editor.fontSize": 14,
"editor.lineHeight": 2.5,
"editor.cursorBlinking": "solid",
"workbench.tree.indent": 20
```

### Coming from Gatito Nightly

Feles used to be called Gatito Nightly. Its Red and Blue themes are now Cinnamon and Russian Blue. Feles is a separate extension.
