# Changelog

All notable changes to Feles Theme are listed here, newest first. Versions before 2.0.0 were released as Gatito Nightly.

## 2.4.0 - 2026-10-31

- Status bar items hover in a solid shade of the accent instead of gray: one step darker in the dark themes and a pale tint in the light themes. The hover stays visible and readable on the accent-colored status bar while debugging.
- The README lists each coat's accent colors, shows its previews under its description, has shorter install steps for Windows and Mac, and recommends the same settings the previews use.
- The Marketplace page header uses the theme's dark background.
- Added this changelog.

## 2.3.0 - 2026-10-18

- Notebook outputs now share the editor background, and hovered or selected cells no longer show the output as a separate rectangle.

## 2.2.0 - 2026-10-18

- Feles is now its own Marketplace listing, Feles Theme (`TaouMou.feles-theme`), separate from Gatito Nightly. Pick a Feles theme again after installing it.
- Added three new coats, each in Dark and Light: Lilac (Catppuccin Mocha and Latte code colors), Chartreux (Everforest) and Tuxedo (Alabaster).
- All fourteen themes now go by their Feles labels in the theme picker, without the old Gatito theme IDs.
- The editor and panel now share one surface, and in the dark themes the frame (title bar, activity bar, sidebar, status bar) is a step darker so they stand out from it.
- Light accents now match the hue of their dark counterparts: Russian Blue Light is teal, and Siamese Light uses a deeper blue.
- List hover is a neutral gray instead of an accent tint, so notification toasts no longer turn red or blue.
- Hovering a tab no longer hides the active tab's underline, and the active tab no longer has an outline.
- Removed the stray lines beside the terminal scrollbar and before its tab list, and the grip dots on resizable edges in the floating layout.
- Input, dropdown and checkbox outlines use the divider color, and the panel gets the same outline as the editor in the floating layout.
- Cinnamon Dark's buttons and badges use a deeper red.
- Git graph labels are readable in Siamese Dark and Cinnamon Dark.
- New extension icon: a paw print with one toe bean per coat.
- New framed preview screenshots of every theme in the README.

## 2.0.0 - 2026-10-18

- Renamed to Feles. The themes are now four cat coats, each in Dark and Light: Cinnamon (formerly Gatito Nightly Red), Russian Blue (formerly Gatito Nightly Blue), Siamese and Marmalade.
- All coats share one low-contrast, JetBrains-inspired UI and the same italics, and differ only in accent and code colors.
- Siamese uses JetBrains Islands Dark and IntelliJ Light code colors, and Marmalade uses Ayu Dark and Ayu Light.

## 1.4.0 - 2026-10-17

- Added Gatito Daylight Red and Gatito Daylight Blue light themes.
- Reworked Gatito Nightly Red and Blue while keeping their subtle look.
- The red themes use a Cherrywood accent, so the UI accent no longer matches the keyword color.
- Theme colors now cover the side bar, panels, terminal, command palette, menus, popups and Settings controls, plus newer VS Code parts such as the modern UI, chat, the source control graph, debugging and testing.
- Consistent italics: functions, built-in types, `this`/`self` and comments are italic; JSON keys, CSS properties and JSX components are not.
- Every syntax color reaches at least 4.5:1 contrast against the editor background.
- Flatter borders: removed the focus outline around the selected file and the separator lines between sidebar and panel sections.
